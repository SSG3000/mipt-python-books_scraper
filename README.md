# Books Scraper — домашнее задание №3 по Python

Локальный самодостаточный учебный проект для сбора данных с сайта [Books to Scrape](https://books.toscrape.com/), сохранения результата, ежедневного запуска и проверки функций через `pytest`.

## Преамбула и дисклеймер

Исходный шаблон задания содержит технические противоречия и не определяет часть контракта. Этот проект сохраняет официальные учебные цели, но вводит явные рабочие гипотезы:

- исходный `Задание.txt` трактуется как Jupyter Notebook с неверным расширением;
- используется Python 3.10+ и HTTPS;
- единственный источник рабочего кода — `scraper.py`;
- результат одной книги имеет фиксированную схему;
- пагинация продолжается по ссылке `next` до её исчезновения;
- `books_data.txt` содержит JSON в UTF-8 и полностью перезаписывается;
- сетевые запросы имеют тайм-аут и проверку статуса;
- бесконечный планировщик работает только в отдельном процессе;
- основные тесты не требуют доступа к внешнему сайту.

Это методические уточнения, а не дополнительные требования преподавателя. Если преподаватель даст другое указание, оно имеет приоритет.

Подробное обоснование находится в файлах:

- [`УЧЕБНЫЙ_РАЗБОР_HW03.md`](УЧЕБНЫЙ_РАЗБОР_HW03.md);
- [`ОТЧЕТ_ПО_ОШИБКАМ_ШАБЛОНА_HW03.md`](../ОТЧЕТ_ПО_ОШИБКАМ_ШАБЛОНА_HW03.md).

## Установка на Windows

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

### Демонстрация одной страницы каталога

```powershell
.\.venv\Scripts\python.exe scraper.py --max-pages 1
```

### Полный сбор и сохранение

```powershell
.\.venv\Scripts\python.exe scraper.py --save --delay 0.05
```

Результат сохраняется в `artifacts/books_data.txt`.

### Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

### Ежедневный планировщик

```powershell
.\.venv\Scripts\python.exe scraper.py --schedule --at 19:00 --delay 0.05
```

Процесс планировщика должен оставаться запущенным. В ноутбуке бесконечный цикл намеренно не стартует.

### JupyterLab

Из корня проекта:

```powershell
.\.venv\Scripts\jupyter-lab.exe notebooks\HW_03_python_ds_2025.ipynb
```

Так JupyterLab и ядро используют зависимости из проектного `.venv`, включая `schedule`.

`HW_03_python_ds_2025.ipynb` — итоговый заполненный шаблон с неизменными
формулировками преподавателя. `HW_03_python_ds.ipynb` сохранён как расширенная
учебная демонстрация проекта.

```python
{
    "url": str,

    "description": str | None,
    "product_information": dict[str, str],

```

## Комментарии по доработкам и гипотезам для задания 1

- **Доработка:** сетевой запрос отделён от чистого разбора HTML.
- **Гипотеза:** цена нормализуется в `float`, рейтинг — в целое число от 1 до 5.
- **Зачем:** чистую функцию `parse_book_html` можно тестировать на фикстуре без сети.
- **Влияние:** `get_book_data` остаётся требуемой публичной функцией, но становится проще и надёжнее.

## Комментарии по доработкам и гипотезам для задания 2

- **Доработка:** переход выполняется по ссылке `next`, предусмотрен контроль цикла.
- **Гипотеза:** `max_pages` — дополнительный параметр только для демонстрации и тестов; по умолчанию собирается весь каталог.
- **Зачем:** нельзя делать 1050 сетевых запросов при каждом учебном запуске ноутбука.
- **Влияние:** полный режим соответствует заданию, ограниченный режим ускоряет проверку.

## Комментарии по доработкам и гипотезам для задания 3

- **Доработка:** настройка и бесконечное ожидание разделены.
- **Гипотеза:** 19:00 — локальное время компьютера.
- **Зачем:** `Run All` должен завершаться, а планировщик — запускаться отдельно.
- **Влияние:** ноутбук демонстрирует расписание, не зависая.

## Комментарии по доработкам и гипотезам для задания 4

- **Доработка:** тесты используют HTML-фикстуры и поддельную HTTP-сессию.
- **Гипотеза:** живая сеть не входит в обязательный набор модульных тестов.
- **Зачем:** сетевой сбой не должен превращаться в ложное падение теста.
- **Влияние:** тесты быстрые, повторяемые и проверяют крайние случаи.

## Комментарии по доработкам и гипотезам для задания 5

- **Доработка:** все обязательные файлы уже собраны локально; удалённый репозиторий не создавался.
- **Гипотеза:** перед публикацией проект проверяется после чистой установки, а секреты не добавляются в Git.
- **Зачем:** публичный репозиторий должен быть воспроизводимым и безопасным.
- **Влияние:** для завершения GitHub-части останется инициализировать Git, создать ветку и выполнить PR по отдельному запросу.
